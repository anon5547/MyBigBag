ให้ AI ควบคุมเครื่องจริง?

AI จะขยับเมาส์และพิมพ์แทนคุณ สิทธิ์หมดเองเมื่อครบเวลา ชักเมาส์ไปมุมซ้ายบนเพื่อหยุดทันที

อินพุต 0เอาต์พุต 0แคช 0 ≈ —เรียก 0 ครั้งล้างแชท
ต้องเป็นโมเดลที่ “ดูภาพได้” ถ้าจะให้ควบคุมหน้าจอ กดทดสอบด้านล่างเพื่อยืนยัน
กรอกเพื่อให้ตัวนับค่าใช้จ่ายแสดงเป็นดอลลาร์ (เว้น 0 = แสดงแต่จำนวนโทเคน)
เบราว์เซอร์ตระกูล Chromium (Edge, Chrome, Brave, Vivaldi, Opera) ใช้ได้ทั้งหมด Firefox ต้องรัน playwright install firefox ก่อน

ให้ AI อ่าน Wiki ของเกมเก็บไว้ในเครื่อง แล้วตอบคำถามเรื่องเกมโดยค้นเฉพาะส่วนที่เกี่ยวข้อง (ประหยัดโทเคน ไม่ต้องยัดทั้ง Wiki เข้าแชท)

หรือพิมพ์ /เรียนรู้ ในช่องแชท ต้องมี Microsoft Edge หรือ Chrome ในเครื่อง ระบบเปิดหน้าเว็บ 1 ครั้งแบบผู้เข้าชม และเคารพ robots.txt
⚠ ข้อตกลงของ Lumivara Online ห้ามใช้โปรแกรมช่วยเล่น บอท หรือมาโคร นอกเหนือจากระบบ Auto Play ของเกม — ใช้ความรู้นี้เพื่อ ถามตอบและวางแผน เท่านั้น อย่าให้ AI ควบคุมเมาส์/คีย์บอร์ดเล่นเกมนี้แทน เสี่ยงถูกระงับบัญชีถาวร

สกิลที่ AI บันทึกไว้ กด “เล่น” เพื่อรันซ้ำโดยไม่เสียโทเคนเลย (ต้องปลดล็อกก่อนจึงจะทำจริง)
