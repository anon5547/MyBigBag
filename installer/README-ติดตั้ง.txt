OmniBrain - ตัวติดตั้ง (Windows 10 / 11)
========================================

ติดตั้ง
-------
1. คลิกขวา OmniBrain-Setup.zip > "Extract All..." (แตกไฟล์ให้ครบทุกไฟล์ อย่าเปิดจากในไฟล์ zip โดยตรง)
2. ดับเบิลคลิก  Install.bat
   - ถ้าไม่มี Python ระบบจะติดตั้ง Python 3.12 ให้อัตโนมัติผ่าน winget
     (ถ้าไม่สำเร็จ ให้ติดตั้งเองจาก python.org โดยติ๊ก "Add python.exe to PATH" แล้วเปิด Install.bat ใหม่)
   - Windows อาจขึ้นหน้าต่าง SmartScreen เพราะไฟล์ .bat ไม่ได้เซ็นชื่อ: กด "More info" > "Run anyway"
3. ทำตามหน้าต่างภาษาไทย: ถัดไป > ติดตั้ง รอ 1-3 นาที > เสร็จสิ้น

เครื่องที่มี Claude Desktop
-------------------------
ตัวติดตั้งจะถามว่าจะเชื่อม OmniBrain เข้ากับ Claude Desktop ไหม (ติ๊กไว้ให้แล้ว)
- ไฟล์ตั้งค่าเดิมของ Claude ถูกสำรองไว้ข้างๆ (.omnibrain.bak) และเซิร์ฟเวอร์ MCP ตัวอื่นไม่ถูกแตะ
- หลังติดตั้งต้อง "ปิด Claude Desktop ให้สนิท" (คลิกขวาไอคอนที่ถาดระบบ > Quit) แล้วเปิดใหม่
- แอป OmniBrain กับ Claude Desktop ใช้ฐานความจำเดียวกัน (%APPDATA%\OmniBrain\agent_brain.db)

ใช้กับ 3 หน้าจอ
---------------
- AI ดูทีละจอ (ค่าเริ่มต้นคือจอที่เมาส์อยู่) เพื่อประหยัดโทเคน และสั่งให้ดูจอที่ 1/2/3 หรือทุกจอรวมได้
- หยุดฉุกเฉิน: ชักเมาส์ไปที่มุมซ้ายบนของจอใดจอหนึ่ง (ทุกจอใช้ได้) ระบบจะล็อกทันที
- แนะนำตั้งค่า Scale ของแต่ละจอใน Windows เท่ากัน จะแม่นที่สุด (ระบบรองรับต่างกันได้ แต่ยังไม่เคยทดสอบบนเครื่องจริง)

การเปิดโหมดควบคุมจริง (ปลอดภัยไว้ก่อน)
--------------------------------------
- เริ่มต้นเป็น "โหมดจำลอง" เสมอ AI ปลดล็อกเองไม่ได้
- ในแอป: กดปุ่ม "ปลดล็อก" (เลือก 5/10/30 นาที หมดเวลาแล้วล็อกกลับเอง)
- ใน Claude Desktop: AI เรียก request_live_unlock จะมีกล่องถามกลางจอให้คุณกด Yes (ปุ่มเริ่มต้นคือ No)
- ปิดเครื่องมือควบคุมเดสก์ท็อป/เทอร์มินัลแบบ auto-run ตัวอื่นของ Claude ไว้ตอนใช้ LIVE
  เพราะมันอาจกดกล่องยืนยันแทนคุณได้

ตั้งค่า API (เฉพาะแอป OmniBrain ที่มีช่องแชทของตัวเอง)
-------------------------------------------------------
เปิดแอป > ไอคอนเฟือง > เลือกค่าย ใส่ชื่อโมเดลและ API key > กด "ทดสอบโมเดล"
(Claude Desktop ไม่ต้องใช้ข้อนี้ ใช้บัญชี Claude ของคุณตามปกติ)

เบราว์เซอร์
-----------
- แอปเปิดได้ด้วย Edge / Chrome / Brave / Vivaldi / Opera / Firefox เลือกที่ ตั้งค่า > "เปิดหน้าแอปด้วย"
- เปิดหน้าเดียวกันพร้อมกันหลายเบราว์เซอร์ได้ จากปุ่มชื่อเบราว์เซอร์ในหน้าตั้งค่า
- ตอนเรียนรู้ Wiki เลือกเบราว์เซอร์ที่ใช้อ่านได้ (Firefox ต้องรัน playwright install firefox ก่อน)

ความรู้เกม (Wiki)
-----------------
- ตัวติดตั้งแถมความรู้จาก Wiki ของ Lumivara Online ที่เก็บไว้แล้ว (มอนสเตอร์ ไอเทม สกิล ระบบเกม) ถามได้ทันที
- อัปเดตให้ใหม่: ในแอปไปแท็บ "ความรู้" แล้วกด "เรียนรู้ / อัปเดต" หรือพิมพ์ /เรียนรู้ ในช่องแชท (ต้องมี Microsoft Edge)
- AI ไม่ได้อ่านทั้ง Wiki ทุกครั้ง (ใหญ่เกินไป) แต่ค้นเฉพาะส่วนที่เกี่ยวข้องกับคำถาม จึงประหยัดโทเคน
- Claude Desktop ก็ถามความรู้นี้ได้ ผ่านเครื่องมือ wiki_search
- ข้อควรระวัง: ข้อตกลงของเกมห้ามใช้โปรแกรมช่วยเล่น/บอท/มาโคร นอกจาก Auto Play ที่เกมมีให้
  ใช้ความรู้นี้เพื่อ "ถามตอบ/วางแผน" เท่านั้น อย่าให้ AI ควบคุมเมาส์เล่นเกมนี้แทน เสี่ยงถูกระงับบัญชีถาวร

ถอนการติดตั้ง
-------------
Settings > Apps > OmniBrain > Uninstall (หรือดับเบิลคลิก Uninstall.bat ในโฟลเดอร์ติดตั้ง)
ตัวถอนจะลบโปรแกรม ทางลัด และเอา omni-brain ออกจาก Claude Desktop และถามก่อนว่าจะลบความจำ/การตั้งค่าด้วยไหม

ติดตั้งที่
----------
%LOCALAPPDATA%\Programs\OmniBrain   (โปรแกรม)      %APPDATA%\OmniBrain   (ความจำ + การตั้งค่า)
